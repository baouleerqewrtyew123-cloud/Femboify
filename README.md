# Femboify
Arch Stereotype Automator — сатирический GUI-инсталлер на Python, доводящий до абсурда мемы про юзеров Arch Linux. Скрипт в один клик превращает систему в пастельный «фембой-сетап».


## Установка зависимостей

Перед запуском **Arch Setup** необходимо установить Python. Для графического интерфейса с котиком также требуется библиотека PySide6.

### 1. Установка Python и PySide6

На Arch Linux и совместимых дистрибутивах выполните:

```bash
sudo pacman -S python pyside6
```

`pacman` установит Python и PySide6, а также необходимые зависимости.

**Примечание:** PySide6 нужен только для графического интерфейса. Для запуска установщика в терминале достаточно Python.

### 2. Проверка установки

Проверьте, что Python установлен:

```bash
python3 --version
```

Проверьте PySide6:

```bash
python3 -c "from PySide6.QtWidgets import QApplication; print('PySide6 работает')"
```

Если обе команды выполняются без ошибок, зависимости готовы.

### 3. Проверка Arch Setup

Перейдите в каталог, содержащий `Arch.py` и остальные файлы проекта. Например, если файлы находятся непосредственно на рабочем столе:

```bash
cd ~/Рабочий\ стол
```

Запустите проверку проекта:

```bash
python3 Arch.py --check
```

Этот режим проверяет синтаксис файлов, импорт модулей, наличие необходимых системных команд и план установки. Он не выполняет установку пакетов и не изменяет системные настройки.

### 4. Запуск установщика

**Графический интерфейс с котиком:**

```bash
sudo -E python3 Arch.py --gui
```

**Режим терминала:**

```bash
sudo -E python3 Arch.py
```

Для выполнения системных настроек установщику необходимы права администратора. Сборка пакетов AUR при этом должна выполняться от обычного пользователя, а не от root.

### Важно

Arch Setup способен устанавливать и удалять пакеты, изменять системные настройки и оформлять рабочий стол. Перед началом установки проверяйте выбранные действия и внимательно читайте запросы на подтверждение.

Если графический интерфейс не запускается, сначала проверьте установку PySide6 и повторите команду проверки проекта.
